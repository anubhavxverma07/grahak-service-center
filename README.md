# Grahak Service Center

A responsive, motion-focused frontend for Grahak Service Center.

## Included
- Responsive landing website
- AEPS, BBPS, Money Transfer, Recharge, PAN Card and DTH service sections
- Service detail interaction
- Partner onboarding UI
- Login UI
- FAQ
- Contact form
- Privacy / Terms placeholders
- Mobile fullscreen navigation
- CSS motion/ambient effects
- Reduced-motion fallback
- No fake financial transactions

## Important
Real AEPS/BBPS/DMT/recharge/PAN/DTH transactions require authorized providers, API credentials, KYC/compliance and a backend. This project intentionally does not fake transaction success.
